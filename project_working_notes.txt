SECTION 1 - PROJECT OVERVIEW
----------------------------------------------------------------
1.1 EcoQuest teaches environmental awareness through gamified
    quizzes, daily practice and practical eco-challenges.
1.2 Backend: Python (Django). Database: SQLite (local only).
1.3 Frontend: responsive HTML5/CSS3/JavaScript templates.
1.4 Progress reports export as CSV / Excel / PDF / JSON.
1.5 Users: school and college students, teachers, awareness
    programs. Admins manage content and view progress.

SECTION 2 - MODULE ARCHITECTURE
----------------------------------------------------------------
2.1 core         : landing, about, privacy, error pages
2.2 accounts     : registration, login, recovery, profiles
2.3 quizzes      : levels, questions, attempts, daily quiz
2.4 gamification : XP, Eco Coins, badges, streaks, leaderboard
2.5 challenges   : eco-challenges with local evidence upload
2.6 analytics    : topic progress, weak topics, charts
2.7 backups      : encrypted export/import with checksum
2.8 local_sync   : consent-based local network sharing
2.9 dashboard    : student and admin dashboards
2.10 admin panel : content and user management

CATEGORY 1: WASTE MANAGEMENT

Q3. What does the 3R principle stand for?

Q3. Give one daily habit that cuts emissions.

CATEGORY 3: WATER CONSERVATION
Q1. How many liters can a leaking tap waste per day?

Q3. Name one way to reuse greywater at home.

CATEGORY 4: ENERGY SAVING
Q1. Which bulb type consumes less power, LED or CFL?
